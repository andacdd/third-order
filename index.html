Products

Two products, one idea: take the manual loop out.

Our long-term focus is social media automation. Along the way we found a concrete, painful problem in Turkish freight logistics and started building for it too.

In development · Web + Android

Yük Pusulası

Load matching for Turkish freight

In Turkey, freight loads are mostly posted as free-text messages in crowded WhatsApp groups. Truck owners scroll for hours; shippers repost again and again. Yük Pusulası turns that stream into a searchable, structured load board.

  • Shippers post loads; carriers search by route, vehicle type, date and tonnage
  • Map view with loads sorted by distance to the carrier
  • A read-only WhatsApp bot that parses group messages into structured listings
  • Phone (SMS OTP) sign-in, Turkish-first UI, KVKK-compliant data handling
  • Progressive web app and a native Android app
In development

Long-form video automation

AI-generated content for social media

Running a long-form video channel means researching, scripting, voicing and editing every episode, which takes days per video. We're building a tool that turns a topic into a finished long-form video, so creators and small brands can publish consistently without a production team.

  • Topic in, finished long-form video out
  • Built for channels that publish on a regular schedule
  • First step toward our broader social media automation platform
How we build

A two-person team that ships like a bigger one, with Claude.

Claude is part of our development process. We use Claude Code to write, test and review the code for both products, which lets two founders cover web, mobile, database and bot work at the same time.

01

Spec and plan

We write specs and architecture decisions in the repo and work through them with Claude before any code is written.

02

Build and test

Claude Code implements features across our Next.js web app, Android app, Postgres migrations and WhatsApp bot, with tests alongside.

03

Review and ship

Every change goes through lint, type checks and tests, plus a review pass, before it reaches our users.
